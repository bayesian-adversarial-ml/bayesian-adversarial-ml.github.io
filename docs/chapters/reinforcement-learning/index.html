Chapter 06

Adversarial issues in reinforcement learning

How can an agent learn when an opponent can interfere with its observations, rewards or actions? Threatened Markov decision processes combine value learning with Bayesian opponent models, illustrated through the friend-or-foe environment.

In this chapter

  • Reinforcement learning
  • Opponent modeling
  • Threatened MDPs
